Pre-processing Data

  • Before feature engineering/selection or modeling it is important to clean the data.

“Garbage In Garbage Out”

Subset Ignoble Variables

  • You are not always going to need every variable in the original dataset.

  • Simply remove any variable you will not need from the data.

  • The method will change depending on the programming language.

Missing Data in Python

  • Imputing data is one of the easiest methods to deal with missing values and NA values.

  • You should save the dataset after changing it from the original. You never know when you’ll need it again.

from sklearn.datasets import load_iris
iris = load_iris()
import pandas as pd
import numpy as np
df = pd.DataFrame(data= np.c_[iris['data'], iris['target']],
                  columns= iris['feature_names'] + ['Species'])
  • Lets use the mean to replace missing and NA values.
missing_col = ['sepal length (cm)']
for i in missing_col:
 df.loc[df.loc[:,i].isnull(),i]=df.loc[:,i].mean()
  • Looping through the columns.
names = list(df.columns)
rang = range(0,len(names))
for i in rang:
  missing_col = [names[i]]
  for i in missing_col:
    df.loc[df.loc[:,i].isnull(),i]=df.loc[:,i].mean()

Outliers in Python

from sklearn.datasets import load_iris
iris = load_iris()
import pandas as pd
import numpy as np
df = pd.DataFrame(data= np.c_[iris['data'], iris['target']],
                  columns= iris['feature_names'] + ['Species'])
  • We will use the median to replace the outliers in the data.
names = list(df.columns)
rang = range(0,len(names))
for i in rang:
  missing_col = [names[i]]
  median = float(df[missing_col].median())
  df[missing_col] = np.where(df[missing_col] > median, median, df[missing_col])

Variable Importance

  • To capture the importance of a variable we must actually build a ml model, train it, and used the trained state to provide the importance measures for each feature.

  • Depending on regression or classification type problem may impact the model technique utilized.

  • A best practice would be to train multiple models and compare the importance of the features within each trained model, which provides a more comprehensive and generalized look at what features to include in your real modeling.
